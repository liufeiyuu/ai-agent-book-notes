## 学习目标

- 用自己的语言复述关键概念，而不只是摘抄原文
- 完成书中的实验和思考题
- 记录实践中的问题、判断与结论
- 建立一套可以持续迭代的 Agent 工程知识库

```text
└── templates/             # 可复制的笔记模板
```

## 记录约定

1. GitHub 中的 Markdown 是笔记的唯一真实来源。
2. 一篇笔记只解决一个主题，文件名使用小写英文和连字符。
3. 摘抄与个人理解分开记录，引用原文时附上来源链接。
4. 实验不仅记录代码，也记录假设、结果、失败和结论。
5. Notion 仅作为便于阅读、筛选和检索的同步副本。
